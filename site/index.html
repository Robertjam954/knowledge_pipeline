What it does

A knowledge system that runs on your machine

Six pieces, one rule: everything derives from markdown you can read, edit, and throw away the cache of.

🗄️

Plain-text vault

No Postgres, no ChromaDB. Markdown plus [[wikilinks]] is the source of truth; BM25 and the graph rebuild in memory and vectors sit in an .npz cache.

🔎

Hybrid retrieval

numpy cosine and BM25 rankings are fused with reciprocal-rank fusion (k=60), then the retriever follows [[wikilinks]] one hop out to pull in what both signals miss.

🧷

Cited answers

Gemma answers strictly from retrieved notes and marks every claim with a bracketed source like [1]. No relevant note, no answer - it says so instead of guessing.

📝

Three-pass drafting

A note becomes a post through draft → rules edit → clarity edit. A code validator then blocks anything that breaks the enforced rules before it can publish.

🏠

Local by default

Gemma 3 runs through LM Studio for private, offline QA. Flip KP_LLM_PROVIDER=anthropic to route drafting and extraction through Claude - same call site, one setting.

🧠

Agent memory

The agent's remember / recall tools write to a Memory/ folder in the same vault - searchable like everything else, and never used as a blog source.

How it works

From a link to a cited answer or a post

The path a source travels, from ingestion to something you can question or publish.

01

Ingest

Web, YouTube, papers, and Apple Notes become atomic Zettelkasten notes in the vault.

02

Index

Chunk each note, embed to an .npz cache, build BM25 and the wikilink graph in memory.

03

Retrieve

Fuse vector and keyword ranks with RRF, then expand along [[wikilinks]].

04

Answer

Gemma responds with numbered citations - or drafts a post from the same notes.

05

Publish

The validator gates the draft, a Vercel deploy hook fires, a Medium mirror is optional.

Architecture

Five kinds of input converge on one markdown vault, then fan back out into answers and posts. The vault in the middle is the only thing that persists.

web / YouTube / papers ──┐
Apple Notes (importer) ────┼──▸ Obsidian vault (markdown + [[wikilinks]])  # only source of truth
agent "remember" ────────┘      │
                             ├──▸ hybrid RAG — numpy cosine + BM25 → RRF → graph expansion
                             │     └─ QA with [n] citations — Gemma via LM Studio
                             └──▸ blog drafts — draft → rules edit → clarity edit
                                 └─ Vercel deploy hook / Medium draft

Run it

Fully offline in two commands

A local-first stack: your machine, your models, your notes. Needs LM Studio serving Gemma 3 and an embedding model on port 1234.

# backend (port 8600)
$ cd backend && python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
$ cp ../.env.example .env  # set vault path + model names
$ .venv/bin/uvicorn app.main:app --reload --port 8600

# index the vault, then ask
$ curl -X POST localhost:8600/index/refresh
$ curl -X POST localhost:8600/ask -d '{"question":"..."}'

# frontend shell (port 5273, proxies /api → 8600)
$ cd frontend && npm install && npm run dev
